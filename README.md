# 🍸 Bar ERP

Барменд болон санхүүд зориулсан хөнгөн ERP — нэг файлд багтсан, интернэтгүй ажилладаг (PWA).

## Хувилбарууд

| Файл | Загвар |
|---|---|
| `index.html` | Харанхуй (dark), дээд цэстэй |
| `v2.html` | Цайвар, хажуугийн цэстэй |

Хоёулаа ижил функцтэй, нэг өгөгдөл (localStorage) хуваалцана.

## Эрхийн систем

- 🍺 **Бармен** (анхны ПИН: `1111`) — Борлуулалт (POS) + Агуулах
- 👔 **Менежер** (анхны ПИН: `0000`) — бүх хэсэг (Санхүү, Тайлан, Тохиргоо орно)

ПИН-үүдийг менежер Тохиргоо хэсгээс солино.

## Функцууд

- **POS**: ангилалтай бараа, сагс, хөнгөлөлт, бэлэн/карт төлбөр, хэвлэгддэг баримт
- **Ээлж**: нээх/хаах, кассын зөрүү тооцоолол
- **Агуулах**: автомат хасалт, доод үлдэгдлийн анхааруулга, орлого авах
- **Санхүү**: зарлагын бүртгэл, борлуулалт цуцлах
- **Тайлан**: орлого/COGS/ашиг, өдрөөр график, шилдэг бараа, ээлжийн түүх, CSV экспорт
- **Өгөгдөл**: JSON нөөцлөх/сэргээх

## Анхаарах

Өгөгдөл хөтчийн localStorage-д хадгалагдана — төхөөрөмж бүр өөрийн гэсэн өгөгдөлтэй.
Тохиргоо хэсгээс тогтмол нөөц (JSON) авахыг зөвлөнө.
